HOW OWNER BUILD WORKS:
1. GitHub Actions workflow private-owner-windows.yml triggered manually (workflow_dispatch)
2. Reads secret MIYU_OWNER_PIN from repository secrets
3. tools/gen-owner-hash.go generates random salt and PBKDF2 hash
4. Salt and hash injected via Go ldflags: -X main.ownerSalt=... -X main.ownerHash=...
5. Build ID injected: owner-<git-sha>
6. Binary built: Miyu-Owner.exe (Windows) or Miyu-Owner-Android.apk
7. ZIP created: Miyu-Owner-Windows.zip containing exe, Owner-Portable.html, this guide
8. Uploaded as private artifact, NOT as public Release
9. Logs redact hash/salt (show [REDACTED])

BUILD COMMANDS (local, for testing, don't commit PIN):

# Generate hash locally (requires Go)
MIYU_OWNER_PIN=mysecretpin go run ./tools/gen-owner-hash.go
# Output: salt=... hash=...
# Then build with ldflags:
cd desktop
go run ./resourcegen
go build -trimpath -ldflags="-s -w -H windowsgui -X main.ownerSalt=<salt> -X main.ownerHash=<hash> -X main.ownerBuildID=owner-local -X main.AppVersion=1.2.0-owner" -o ../Miyu-Owner.exe .

For Android Owner:
cd mobile/android
./gradlew assembleDebug -PownerBuild=true
